# 12. ERC-20 Tokens – WeightedVoting

**Solution:** [`contracts/WeightedVoting.sol`](../contracts/WeightedVoting.sol)

## Task
An OpenZeppelin ERC-20 with claimable tokens and weighted voting on issues; issues store voters in an `EnumerableSet`.

## How the solution works
`EnumerableSet` can't be returned, so `getIssue` returns a view struct with `voters` as an array. Check token ownership **before** the quorum check.
