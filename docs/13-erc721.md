# 13. ERC-721 Tokens – HaikuNFT

**Solution:** [`contracts/HaikuNFT.sol`](../contracts/HaikuNFT.sol)

## Task
Mint unique haikus as NFTs (ids start at 1), share them with other addresses and read the haikus shared with you.

## How the solution works
Uniqueness is tracked by hashing every line; `getMySharedHaikus` reverts with `NoHaikusShared()` when empty. Pins for this exercise can only pass once per wallet.
