Base Learn Pins

All 13 Solidity exercises · Base Sepolia testnet
Pins: –/13

Each exercise: your wallet deploys the solution contract on Base Sepolia, then calls the official Base Learn unit-test contract with its address. If the test passes, the test contract mints a soulbound NFT pin to your wallet. Guild.xyz “Base Learn” roles check these pins. Everything is on the testnet — it uses free test ETH only.

You need a little Base Sepolia test ETH (≈0.005 is plenty for all 13). Get it free from a faucet, e.g. Coinbase Developer Platform faucet or Alchemy Base Sepolia faucet.
